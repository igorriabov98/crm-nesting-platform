## Данные и выпуск

- До миграций проверена физическая резервная копия Supabase проекта `rmnciwiksbfxfsfomvig`: **2026-09-21 00:09:23 UTC**, Database → Backups → Scheduled backups.
- Первая миграция сохраняет определения изменяемых функций и их ACL, матрицу, корректировки, архивные связи, затронутые задачи и строки CIV-19-2026 в закрытой таблице `private.revision_procurement_release_snapshot` с `captured_at`.
- Узкое восстановление статуса относится только к пяти проверенным строкам CIV-19-2026 с существующим активным графиком и поставщиком. Возвращённая позиция с отменённым графиком исключена. Перед обновлением состояние проверяется повторно; резерв, количество и фактическая приёмка не создаются.
- Старые утверждённые снимки не переписываются. Если в старой версии не сохранилась раскладка, выводится отсутствие сведений, а не подстановка текущей потребности.
- Новая таблица группы доступна обычным пользователям только для чтения через RLS родительской корректировки. Изменения выполняются триггерами жизненного цикла.
- SQL-проверки выполняются на отдельной локальной тестовой БД. Действия приёмки, резервирования и согласования рабочих production-заявок не выполняются для демонстрации.
- Выпуск: CI → merge main → штатный deploy workflow с `deploy_railway=false`, `read_only_smoke=true`. После выпуска сверяются SHA, migration ledger и интерфейс.
